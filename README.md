# Ravada Khageswararao – Official Google Knowledge Panel Developer Portfolio

An interactive, pixel-perfect Google Search Knowledge Panel web portfolio for **Ravada Khageswararao** (Frontend & Mobile Software Engineer).

Built with embedded **Schema.org JSON-LD** structured data to optimize for Googlebot indexing and Google Knowledge Graph recognition.

## 🚀 Key Highlights & Features
- **Exact Google Knowledge Panel UI**: Styled after Google Mobile & Desktop Search entity cards (matching Google Sans typography, card radii, and color palettes).
- **Dynamic Age Calculation**: Dynamically computes exact age in real-time from birthdate (`24 December 2007`).
- **Web Speech Synthesis Audio**: Native audio pronunciation of *Ravada Khageswararao* via the speaker icon.
- **Projects Carousel (in place of Movies)**: Displays horizontal poster cards for:
  1. **LendSwift** – 8-Step Loan Application with AES-256-GCM encryption & Verhoeff KYC
  2. **Sankalp HRMS** – Google-indexed enterprise workforce operations platform (`sankalp ip khageswararao`)
  3. **Harbour Link** – Real-time maritime AIS radar transit dashboard
  4. **Native Android Music Player** – Offline audio player targeting Android SDK 36 with Kotlin foreground services
  5. **PayPulse Neo** – Soundbox and QR payment simulation engine
  6. **Blood Donation System** – Python (Flask) & SQLite matching portal
  7. **Highway Racing Game** – 2D HTML5 Canvas continuous collision physics
- **SEO & Googlebot Optimization**: Complete Schema.org `Person`, `SoftwareApplication`, and `OfferCatalog` metadata embedded in `<head>` for search engines.
